# DeskSwipe — 自作PC & デスク環境シミュレータ

用途や好みに合わせた自作PCとデスク周りの構成をシミュレーションできるWebツールです。

## 特徴

- **構成シミュレーション**: 用途（日常事務、ゲーミング、AI開発など）や予算に応じたパーツ構成の選定
- **パーツ選定と比較**: 主要パーツのスペック比較と価格目安の確認
- **保存と共有**: 作成した構成の保存やURL共有機能

## 使い方

1. **用途・スタイルの選択**: 画面の案内に沿って、主な使用目的や希望のスタイルを選択します。
2. **パーツのカスタマイズ**: 提案された構成を確認し、必要に応じて各パーツを変更・調整します。
3. **構成の確認・保存**: 合計金額や詳細スペックを確認し、URLのコピーや構成の保存を行います。
