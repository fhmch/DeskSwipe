# ⚡ 01_DeskSwipe — DESK & PC BUILD STUDIO (多面カウンセリング ＆ 複数候補選定)

## 概要
「多面的な要件カウンセリング」「複数メーカー候補の並列比較」「高精細実写写真」「リアルタイム・ビルドキャンバス」を融合させた、自作PC＆デスク環境のインタラクティブ選定Webアプリケーションです。

---

## 🎯 主な新機能とアーキテクチャ

### 1. 🧠 多面的な要件カウンセリング（1問即決の廃止）
- 1問で全部決める乱暴さを排除し、専門家がカウンセリングするように精密に要件をヒアリング：
  - **性能選定（全4問）**: 作業領域（AI/ゲーム/動画/CAD） ➔ ターゲット解像度 ➔ マルチタスク規模（Docker/メモリ64GB） ➔ 予算レンジ
  - **外観選定（全3問）**: 部屋のインテリア世界観（2面ガラス/無垢材/白ミニマル） ➔ モニター環境 ➔ タイピング感触

### 2. 🛒 各パーツの「複数有力候補（メーカー/特徴別）」並列提示
- 1つの商品だけを断定するのではなく、条件に合致する**2〜3種類の現実的な選択肢（例: ASUS TUF 3連ファン / MSI Ventus 小型 / GALAKURO White 等）**を提示。
- ユーザーが好みのメーカーや見た目・価格で自由に比較・確定・差し替えが可能。

### 3. 📸 高精細実写写真 ＆ ベクターのハイブリッド表示
- デスク環境、ピラーレスPC、木製無垢材ケース、曲面モニター、縦横デュアル、HHKB、カスタムキーボード、グラフィックカードなどの美しい高解像度写真を配置し、完成空間を直感的にイメージ可能。

### 4. ⚡ リアルタイム・ビルドキャンバス
- 画面上部に全8パーツの設計図キャンバスを常時配置。
- 各スロットをクリックすると、いつでもそのパーツの「複数候補比較画面」が開き、ピンポイントな差し替えや最安値チェックが可能。
